MediTrack+

Never Miss a Medicine. Stay in Control of Your Health.

MediTrack+ is a smart medicine reminder and medication management web application developed for PROMPTWARS 2026 – PS02 (Healthcare: Smart Medicine Reminder).

It aims to make everyday medication management simpler, more organised, and accessible, particularly for people managing multiple medicines and caregivers supporting them.

🌐 Live Demo

"Open MediTrack+" (https://meditrack-plus.meditrackplus.workers.dev)

🎯 Problem Statement

People who take multiple medicines may struggle to remember medication schedules, track completed doses, and maintain a consistent medication routine.

MediTrack+ addresses this challenge through a simple digital platform for organising medicines, tracking doses, and reviewing medication history.

✨ Key Features

- Medicine Management: Add and manage medicines and their schedules.
- Dose Tracking: Mark individual doses as Taken.
- Medicine Reminders: Browser-based reminders while the application is open.
- Medication History: Review previously recorded dose activity.
- Analytics Dashboard: View medication tracking and adherence information.
- Accessibility Options: Designed with usability and readability in mind.
- Caregiver Demonstration Mode: A local demonstration of caregiver-related functionality.

Installation

Clone the repository:

git clone https://github.com/paulbiraj/meditrack.git

Move into the project directory:

cd meditrack

Install dependencies:

bun install

Start the development server:

bun run dev

Open the local URL displayed in your terminal.

⚠️ Current Limitations

- Browser-based reminders work while the application is open; closed-app push notifications are not implemented.
- Caregiver mode is a local demonstration and does not provide remote caregiver synchronization.
- The current application does not provide cross-device cloud synchronization.
- MediTrack+ is a medication tracking tool, not a replacement for professional medical advice or prescriptions.
